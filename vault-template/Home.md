# Home

Welcome to your second brain. This vault is shared between you (in Obsidian) and Claude (in Custard).

## How it's organized

| Folder | What goes there |
| --- | --- |
| [[Inbox/README\|Inbox]] | Quick captures to sort later |
| [[Projects/README\|Projects]] | Things with a goal and an end date |
| [[Areas/README\|Areas]] | Ongoing responsibilities: health, money, work, home |
| [[Resources/README\|Resources]] | Reference material and topics you're interested in |
| [[Archive/README\|Archive]] | Finished or inactive notes |
| [[Daily/README\|Daily]] | One note per day, named `YYYY-MM-DD` |
| [[Reviews/README\|Reviews]] | Weekly reviews |
| Templates | Starting points for new notes |
| [[Custard/README\|Custard]] | Claude's memory and skills |

## Working with Claude

Ask Claude in Custard things like:

- "What do my notes say about…?"
- "Start a daily note for today."
- "Kick off a project for…"
- "Do my weekly review."
- "Remember that I…"

Claude can read everything here, create notes and add to notes, but it never overwrites or deletes anything.
