# Project kickoff

1. Search the vault for the project name to avoid duplicates.
2. Ask only what you can't infer: what done looks like, and any deadline.
3. Read `Templates/Project.md` and fill it in:
   - `{{title}}` → the project name; `{{date}}` → today.
   - **Goal:** one or two sentences, concrete and checkable.
   - **Why:** the user's reason, in their words.
   - **Next actions:** three to seven small tasks as `- [ ]` checkboxes, the first doable in under an hour.
   - **Links:** `[[wikilinks]]` to related Areas or Resources found in search.
4. Create it at `Projects/<Project Name>.md`.
5. Append a one-line entry to `Custard/Memory.md` under the log, e.g. `- 2026-10-07: Started project [[Projects/Custard]].`
